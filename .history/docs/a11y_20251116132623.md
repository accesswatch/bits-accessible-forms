# Accessibility (WCAG 2.2 AA)

## Key SC Mappings
- 1.3.1 Info & Relationships: labels, fieldsets/legends, semantic headings
- 1.4.3 Contrast (AA): tokenized colors ensure ≥ 4.5:1 text; ≥ 3:1 UI (1.4.11)
- 1.4.10 Reflow: two-column auto-stacks; 320px width support without horizontal scroll
- 1.4.12 Text Spacing: no content loss with standard spacing overrides
- 1.4.13 Content on Hover/Focus: tooltips dismissible, persistent on hover/focus
- 2.1.x Keyboard: complete keyboard operation; no traps
- 2.4.3 Focus Order: logical tab sequence; hidden/disabled fields removed from order
- 2.4.6 Headings & Labels: descriptive labels and headings; auto-outline + lint
- 2.4.7 Focus Visible; 2.4.11 Focus Not Obscured (Minimum)
- 2.5.7 Dragging Movements: button/keyboard alternatives for drag (Jump Move)
- 2.5.8 Target Size (Minimum): min 24×24 hit targets
- 3.3.1/2/3 Error ID/Instructions/Suggestion: inline + summary; suggest corrections
- 3.3.4 Error Prevention (Legal/Financial): review pattern; refunds; clear confirmations
- 4.1.2 Name/Role/Value; 4.1.3 Status Messages: ARIA roles; announcements

## Admin (Builder) Keyboard/SR
- Tabs: role=tab + aria-controls; Ctrl+Arrow switches; Alt+1..9 jumps; focus lands on first control; Esc returns to Canvas.
- Dialogs: role=dialog; labelled by title; initial focus; Esc closes; focus returns to trigger.
- Combobox (Move tab): ARIA 1.2 with listbox; announce result counts; grouped headings; Enter select; Esc close; Home/End jump.
- Tables (Choices): cells labelled by headers; keyboard edit; Alt+Arrow reorders; announcements on move/add/errors.
- Live Regions: announce move success/invalid; delete/undo; bulk parse results.
- Targets: controls ≥24×24; maintain focus-not-obscured using scroll padding.

## User (Renderer)
- Error summary with in-page links; aria-live polite; first invalid focus.
- Per-field aria-invalid/aria-describedby; group legends.
- Pagination announcements confined; no focus theft on logic changes.

## Testing
- Automated: axe-core/Lighthouse CI gates; fail on serious violations.
- Manual: keyboard-only flows, SR passes (NVDA/JAWS/VO), zoom/reflow tests, payments flows.
