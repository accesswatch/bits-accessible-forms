# Authoring Guide

## Tips
- Use clear labels; avoid placeholder-only labels.
- Organize with Sections; rely on auto-outline; override heading levels only when needed.
- Keep logic simple; prefer show/hide over disable unless you must show state.
- Use Error Summary: fix from top links; each field highlights errors inline.
- Pricing: define products/options clearly; test with coupons; verify totals preview.
- Taxes: set nexus and manual rules; require billing address fields as configured.
- Payments: use test mode to validate flows; check webhooks status; reconcile totals.
