# Disable VS Code Workspace Trust Prompts (Sample)

This workspace contains a small set of files to help you disable the VS Code "Workspace Trust" prompts and to show which workspace settings to remove if they are overriding your user preferences.

Files added:
- `settings-no-trust.json` — sample JSON you can paste into your **User Settings (JSON)** to stop trust prompts.
- `remove-these-lines.txt` — lines you should remove from a workspace's `.vscode/settings.json` to avoid overrides.

Quick steps (recommended)
1. Open VS Code.
2. Press `Ctrl+Shift+P` → `Preferences: Open Settings (JSON)` to open your User settings file.
3. Copy the contents of `settings-no-trust.json` into the User settings JSON (merge with existing keys).
4. Save and restart VS Code.
5. Open any workspace and check `.vscode/settings.json` for any lines listed in `remove-these-lines.txt`; remove them if present.

Settings snippet (copyable)

```json
{
  "security.workspace.trust.enabled": false,
  "security.workspace.trust.untrustedFiles": "open"
}
```

What this does
- `security.workspace.trust.enabled: false` disables the workspace trust feature entirely (no trust prompts).
- `security.workspace.trust.untrustedFiles: "open"` makes VS Code open files from untrusted workspaces without prompting.

Cautions
- Disabling workspace trust reduces VS Code's protections: extensions and tasks may run without prompt. Only do this if you understand and accept the security tradeoff.
- If your machine is managed by an organization, group policy or admin settings may re-enable or block changes.
