# Contributing

## Requirements
- WordPress ≥ 6.5, PHP ≥ 8.1, Node ≥ LTS.

## Branching
- `main` (stable), `develop` (next), `feature/*`.

## Testing
- PHP unit/integration (WP REST server), JS unit (React/RTL), E2E (Playwright), axe CI.

## Commits & PRs
- Conventional Commits.
- Include tests and docs updates; CI must pass.
