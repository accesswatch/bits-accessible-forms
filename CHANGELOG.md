# Changelog

All notable changes to the BITS Accessible Forms documentation will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-11-16

### Added
- Complete documentation set for BITS Accessible Forms WordPress plugin
- Architecture documentation covering components, key flows, extensibility, performance, and security model
- Comprehensive schema documentation defining form structure, fields, logic, and settings
- Release process guide covering versioning, pre-release, migrations, docs, and build steps
- Accessibility (a11y) documentation for WCAG 2.2 AA compliance
- Builder UI documentation covering canvas, field library, settings panels, and keyboard navigation
- Renderer UI documentation for front-end form display and interactions
- Contributing guide with requirements, branching strategy, testing approach, and commit conventions
- Decisions documentation capturing key architectural and feature decisions
- Database schema documentation for custom tables (forms, entries, meta, drafts, payments)
- Diagnostics documentation for safe mode, logic overlay, trace logs, and feature flags
- REST API documentation covering endpoints for forms, submissions, entries, and admin operations
- Security documentation covering CSRF protection, validation, anti-spam, rate limiting, and privacy
- Payments documentation for Stripe and PayPal integration
- Taxation documentation for manual tax tables and pricing calculations
- Notifications and confirmations documentation
- Entries export documentation
- Theming documentation for design tokens and CSS customization
- Roadmap with 10 milestones from data model through polish and docs
- Sample form JSON demonstrating registration with payment flow

### Documentation Structure
- Main README in docs/ folder providing project overview, goals, and non-goals
- 20 detailed documentation files covering all aspects of the plugin
- Example forms directory with sample JSON schema
